🌤️ Frequently Asked Questions (FAQ)

1. How does this website get weather data?

This website uses the OpenWeatherMap API to fetch real-time weather information based on the city you enter.

2. Why do I see "Weather data not found for this city"?

This may happen due to incorrect city name, a misspelling, or network/API issues. Try entering just the city name like "Delhi".

3. What unit is used for temperature?

Temperature is shown in degrees Celsius (°C).

4. Can I check international city weather?

Yes. You can enter cities like New York, Tokyo, or use format like Paris,FR.

5. Why does the weather take time to load?

It depends on your internet speed and the OpenWeatherMap API response time.

6. What technologies is this site built with?

HTML, Tailwind CSS, JavaScript, and OpenWeatherMap API.

7. Do I need to log in?

No login is required. This weather tool is completely free to use.
